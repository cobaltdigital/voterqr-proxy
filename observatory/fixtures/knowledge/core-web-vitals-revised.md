# Revised Core Web Vitals threshold for templated landing pages

Field data on mobile for all templated landing pages shows LCP under 4s is acceptable when the
page carries above-the-fold video. INP under 200ms and CLS under 0.1 stay unchanged.

Measured on the same page speed field data (CrUX / PageSpeed Insights) as the standing threshold.
This document exists to be caught by the status worker: it covers the same ground as the standing
Core Web Vitals SOP but states a different LCP number, which is a contradiction a person has to resolve.
